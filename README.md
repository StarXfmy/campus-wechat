# 木鱼 · 微信校园助手

把自己写的校园助手接进微信：**UI 自动化收发消息 + 共享 Python 大脑**。
和 [campus-muyu](https://github.com/StarXfmy/campus-muyu)（飞书端）共用同一份大脑代码，
查询、课表、记忆、知识库这些逻辑两端完全一致，差别只在入口能力。
唯一的例外是提醒：逻辑一样，但微信端不接（到点没有发出去的链路，见技术文档 7.4）。

## 结构

```
微信 PC 4.x
   │  ① 只读本地数据库收消息
   ▼
examples/wechatauto_bridge.py     ← 桥接（本项目主体）
   │  ② UIA 定位输入框、模拟打字发送
   │  POST http://127.0.0.1:8790/chat
   ▼
校园大脑（campus-muyu 里的 campus-feishu-agent）
```

三个进程：微信、桥接、大脑。中间层 Node「鲸鲸娘」已下线，目录保留只为回退。

## 桥接负责什么

- **平台判定**（`examples/wx_behavior.py`）：群里只认 @ / 引用 / 正文提到「木鱼」；
  非主人 22:00–08:00 静默；30 秒冷却排队补答（不丢消息）；每天/每小时上限；闭麦只主人可开。
- **发送队列**：冷却与随机等待在独立线程里消化，读消息不被阻塞。
- **识图**（`examples/wx_vision.py`）：微信 wxgf/HEIC 先转码，再交给视觉模型；按气泡左右分说话人。
- **安全**：微信数据库只读、红包只提醒不代领、主人判定只有一处、被骂撒娇不还口。

## 快速开始（Windows）

1. 微信 PC 4.x 登录（用专用小号）
2. 先启动大脑：`campus-muyu` 里 `启动微信大脑.bat`（8790）
3. 再启动桥接：`启动微信桥接.bat`
4. 把 `config.example.json` 复制为 `config.json`，填 `persona.master.wxids`（只认这一个主人）

## 风险与边界

- UI 自动化不是微信官方接口，**有账号风险**，只建议小号 + 自己的测试群。
- 只读数据库、不写、不注入进程；发消息靠模拟键盘，慢（一条回复 2–12 秒）。
- 电脑必须开着、微信窗口不能被遮住。
